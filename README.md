# MORPH web

Sitio web de MORPH (HTML, CSS y JavaScript sin dependencias).

- `portfolio/` — página principal (index.html, styles.css, main.js, logo-dots.js)
- `img/`, `video/`, `audio/`, `fonts/` — recursos
- `Legal.dc.html` — información legal

## Ver en local

Ejecuta `Server.bat` (necesita Python) y abre http://localhost:8080/portfolio/

Nota: la licencia web de la tipografía Saans (`fonts/`) está pendiente de confirmar antes de publicar el sitio.
